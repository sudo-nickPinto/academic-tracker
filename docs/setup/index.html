Setup

One-time setup for a fresh fork of this dashboard. Fill this in once, right after forking — it configures this repo's site settings and adds your first class, straight from the browser.

Your repo

The GitHub repo this fork lives in — everything below commits directly to it via the GitHub API.

GitHub token

Create a fine-grained personal access token at github.com/settings/personal-access-tokens/new, scoped to just the repo you typed above, with these repository permissions:

  • Contents: Read and write
  • Actions: Read and write — lets it trigger a rebuild right after a commit
  • Metadata: Read-only — required by GitHub for every fine-grained token

The token is stored only in this browser's local storage — never written to any file in the repo. Once saved here, Settings and Manage already have it too.
