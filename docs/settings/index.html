Settings

Connect a GitHub token so the Manage page and the "Mark done" buttons can commit directly to this repo from your browser.

GitHub Token

Create a fine-grained personal access token at github.com/settings/personal-access-tokens/new, scoped to just this one repository (sudo-nickPinto/academic-tracker), with these repository permissions:

  • Contents: Read and write
  • Actions: Read and write — lets it trigger a rebuild right after a commit
  • Metadata: Read-only — required by GitHub for every fine-grained token

The token is stored only in this browser's local storage. It's never written to any file in the repo, and never leaves this browser except in requests sent directly to GitHub's API. Clearing it here (or clearing this site's browser data) removes it completely. It won't sync to your other devices — set it up again on each one.
