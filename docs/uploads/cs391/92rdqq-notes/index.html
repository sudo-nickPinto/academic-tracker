Securing Glatfelter Hall

  • Security controls:

    • Physical: Something real that actually prevents someone or something from getting inside, physically
      • S.Kim acting as the bouncer outside of Glatfelter
      • Doors don't open until validated ID scan
      • Biometric scanning to open Macbook
      • Traditional lock/key on utility doors
    • Administrative: Policies; where we tell entities 'how to behave'
      • Passwords be >= 8 chars
      • ID Scanner only works for buildings deemed 'open 24 hours'
        • e.g Library should not allow someone in at 3am
      • Incident response as to what happens if an intruder enters the building
      • Require password updates after 90 days
      • Security awareness initiatives (phishing, simulations, etc.)
      • Access Control / Permissions
    • Technical: Cybersec pieces; network, computer, technical details
      • ID scanner must support RFID technology
      • Device must be successfully connected to network to log in using SSO
      • Firewall
      • Encryption/MFA
